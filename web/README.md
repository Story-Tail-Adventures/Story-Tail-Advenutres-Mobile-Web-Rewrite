# `web/` — Next.js + React + TypeScript

The web application covering both the authenticated portal (client and agent surfaces) and the public marketing-adjacent pages (which need SEO).

## Status

**Not yet initialized.** This directory exists as the placeholder for the web codebase.

## Initialize

```bash
cd web
pnpm create next-app . --typescript --tailwind --app --src-dir=false \
  --import-alias "@/*" --no-eslint=false --use-pnpm
```

(Adjust flags to taste. The recommended starting setup: TypeScript, Tailwind CSS for the styling layer over our CSS tokens, App Router, src-dir off, `@/*` import alias.)

## Next steps after init

1. **Drop in the design tokens.** Copy `../design/web-tokens/tokens.css` into `styles/tokens.css` and import it from `app/layout.tsx`. Add `import "../styles/tokens.css"` at the top of the root layout.

2. **Wire Tailwind to the tokens.** In `tailwind.config.ts`:
   ```ts
   import { tokens } from "../design/web-tokens/design-tokens";
   export default {
     content: ["./app/**/*.{ts,tsx}", "./components/**/*.{ts,tsx}"],
     theme: {
       extend: {
         colors: tokens.colors,
         fontFamily: tokens.fonts,
         borderRadius: tokens.radii,
       },
     },
   };
   ```

3. **Bundle the fonts via `next/font`** — Poppins, Caveat, JetBrains Mono. Do not load from Google Fonts CDN at runtime in production.

4. **Set up the Supabase client** with public anon key for browser usage and (server-side only) the service role key for protected operations.

5. **Build the first screen**: Login (Screen Inventory 2.1.1) end-to-end as the proving exercise. See `../docs/Tech-Recommendations.md` §5.3 Step 6.

## Environment variables

Once initialized, this project will need a `.env.local` (gitignored) with:

```
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
NEXT_PUBLIC_STRIPE_PUBLISHABLE_KEY=
SUPABASE_SERVICE_ROLE_KEY=         # server-side only — never expose to the browser
STRIPE_SECRET_KEY=                  # server-side only
```

`.env.example` should ship with the project showing the variable names (without values).
